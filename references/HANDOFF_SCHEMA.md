# Editing Handoff Schema

Use this interface before humanization or a major rewrite.

```text
DOCUMENT TYPE:
CORE THESIS:
FACTS LOCK:
OWNERSHIP LOCK:
TECHNICAL LOCK:
PROGRAM FIT LOCK:
CAREER GOAL LOCK:
APPLICANT VOICE:
EDITORIAL INTENT:
TARGET DRAFT:
```

If a field is unknown, mark it unknown. Do not infer a lock from convention or convenience. When two fields conflict, pause that part of the edit and surface the conflict.
