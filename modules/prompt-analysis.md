# Prompt Analysis

Extract the deliverable type, exact questions, required topics, audience, length, formatting constraints, and deadline. Separate explicit requirements from inferred evaluation criteria.

Build a compact prompt map:

- **Must answer:** every explicit question.
- **Must prove:** qualities the committee needs evidence for.
- **Useful context:** information that helps interpretation but does not deserve its own paragraph.
- **Exclusions:** material that is impressive but does not answer this prompt.

Flag compound prompts and assign each part enough space. Treat a word limit as a design constraint, not a trimming task at the end.
