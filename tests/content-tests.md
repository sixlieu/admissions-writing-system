# Content Tests

Use a real prompt and draft. Verify that a reviewer can point to where each prompt part is answered and where each central claim is supported.

Failure cases:

- removing an anecdote collapses the thesis because no other evidence supports it;
- a paragraph is impressive but cannot be tied to the prompt;
- the conclusion introduces a goal absent from the body;
- the essay relies on chronology as proof of growth.

Pass only when revisions address the underlying content rather than merely adding transitions.
